# dsh-agent-panel · 智能体面板与费用参考

一个 DeepSeek Harness 效率插件:在右侧边栏常驻一个「智能体」面板,集中管理子智能体的打开、排序、分组、改名与费用参考,并顺手修复官方界面几处细节。

## 功能

- **常驻智能体面板**:右侧边栏新增「智能体」标签页,大字树形展示全部子智能体
  - 点击行 → 在当前面板直接打开该子智能体对话,主对话窗口保持不变
  - 行尾按钮 → 在主对话窗口打开
- **拖拽排序**:拖行改变顺序;拖到分组行中间放入分组、边缘排在前后,分组本身也可拖拽排序
- **两级自定义分组**:「+ 分组」创建,可改名、折叠、删除(删除仅解散,不删数据);折叠/展开状态持久化,重启保留
- **改显示名**:✎ 修改显示名(不动真实会话数据),留空恢复原名;改名同步到侧栏对话标签页的标题 chip;新名带「-重启有效」标记,重启后只剩纯名字(验证持久化生效)
- **费用参考**:每个子智能体行、分组小计、面板合计、主会话顶部栏右侧胶囊,统一按「累计 tokens × 单价」估算
  - 单价在面板头部「合计」旁输入框自定义(元/百万 tokens,默认 4),持久化保存
- **界面细节修复**:加大官方 header 下拉树的点击区与字号;提高右侧栏小字对比度与渲染清晰度

## 安装

**npm(推荐)**

```sh
dsh plugin --profile web add dsh-agent-panel
```

桌面端(DeeSeek Harness Desktop)在应用内 **设置 → 插件** 搜索安装;安装后重启或刷新页面,在右侧栏「指南」页点「智能体树」打开面板。

**手动 link**

```jsonc
// ~/.dsh/profiles/<profile>/package.json
{
  "dependencies": { "dsh-agent-panel": "link:<本目录路径>" },
  "dsh": { "profile": { "bundles": ["...", "dsh-agent-panel"] } }
}
```

在 profile 目录执行 `pnpm install` 后重启。

## 说明

- 排序/分组/改名/单价只保存在你自己的 profile 存储域,不上传任何数据
- 面板样式依赖 DSH 0.2.2-rc.3 线(声明于 `engines.dsh`)编译产物的哈希类名;DSH 升级后若下拉树样式失效,按 client.js 顶部注释的方法刷新
- 费用为参考估算值,非账单金额;单价请按你的实际平均成本设置(可在面板内直接改)
- 兼容性:要求 `@deepseek-ai/dsh-web-app` / `dsh-client-ui-sidebar-right` 等 0.2.2-rc.3 线组件
